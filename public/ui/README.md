# Runtime UI assets

`menu-light.png`, `menu-dark.png` and `wordmark.png` were generated with the built-in ImageGen tool from the selected option-2 reference. Their exact prompts, input references and original output paths are stored in the matching JSON and embedded in each PNG. Backgrounds contain scenery only; interactive controls and the two existing skins remain real runtime content.

The menu renders backgrounds with `cover`, preserving their ratio. The transparent wordmark uses `contain`. No mockup screenshot is used as the interface.

UI icons come from `@phosphor-icons/core` 2.1.1, using the supplied Bold and Fill SVGs. See `PHOSPHOR-LICENSE.txt` for the MIT copyright and permission notice.
