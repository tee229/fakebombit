# Built-in feedback audio

Eight original mono 16-bit / 22,050 Hz PCM WAV cues are generated by `pnpm art:feedback`. No external samples or runtime randomness are used. Candy uses soft bell harmonics and crisp sugar-like noise; factory uses lower, lightly metallic harmonics and wooden noise. Explosion, break, pickup and elimination cues are 0.22–0.36 seconds.

These are optional presentation assets loaded once by Phaser. Missing or browser-locked audio is skipped without affecting gameplay or replaying when sound becomes available. Per-run voices are bounded, destroyed on completion, pause, view switch and exit. Device loudness and speaker quality need physical-device listening.
