# 微信小游戏开发与验收

#17 使用正式小游戏 AppID `wx72341ad00af05fe1`。在微信开发者工具中导入**仓库根目录**，读取 `project.config.json`；小游戏入口为生成目录 `dist/wechat/game.js`，不是普通小程序页面，也不是 `dist/web`。

## 构建与运行

使用 Node ≥24.12、pnpm 10.27.0，以及 PATH 中的 FFmpeg。也可通过 `FFMPEG_PATH` 指定可执行文件。本机已验证 FFmpeg 位于 `D:/Tools/ffmpeg-7.0.2-full_build/bin/ffmpeg.exe`。

```powershell
pnpm install --frozen-lockfile
pnpm build:wechat
pnpm typecheck:wechat
pnpm test:wechat
```

`test:wechat` 需要先生成 `dist/match`，首次运行先执行 `pnpm build:core`。`pnpm check` 包含所有类型检查、原有规则/流程测试、架构检查、浏览器构建、小游戏构建和小游戏运行时测试。

已验证微信开发者工具 Stable 2.02.2609240、基础库 3.17.6，项目配置固定此基础库。保持工具登录，在工具中打开仓库、编译后即可游玩。修改代码后重新运行 `pnpm build:wechat` 并重新编译。`project.private.config.json`、`dist/` 和本地凭据不入库。服务端口需由用户在安全设置中开启；无需把 MCP 令牌写入工程。

## 平台边界

`src/wechat/main.ts` 组合原有 `createGameFlow`、`createPlayerInput`、资源准备、皮肤播放及反馈模块。`src/match` 没有改动；对局仍是原有固定步进、17×15 生成地图、1对3普通 AI、120 秒与原种子重试。平台时钟、随机种子和 wx API 均留在适配层。

小游戏使用原生 Canvas2D、`wx.createImage`、`wx.createInnerAudioContext`、原生存储及触控事件，不引入 DOM/BOM 或把 Phaser 的浏览器入口直接运行在微信中。Canvas 按窗口逻辑尺寸布局，像素比例上限 3；横屏运行，避开安全区和原生胶囊。微信已经提供全屏承载，局内工具栏保留暂停、设置、明暗与实体视图。

两主题、两皮肤、角色动画、实时侧卡、危险区域、道具、粒子、明暗菜单与设置沿用现有资源和契约。固定/浮动摇杆与放弹按触点标识独立持有；松开放弹不取消仍按住的摇杆。四项边距保存期望值，窗口约束只调整实际位置；恢复操作默认值保留音量和外观。

隐藏、音频中断或窗口变化会暂停、清空输入并停止音效。回来需要手动继续，不追赶后台时间。音乐为应用级单实例，首次操作后播放，暂停采用 pause，跨局继续；音效为每局最多六个实例，退出或重开销毁。背景音乐和音效独立音量、独立保存。真机首次播放、静音开关影响、听感与切后台续播仍须人工确认。

## 素材与包体

构建脚本只重建 `dist/wechat`。原始 `public/` 资源不变：SVG 图集转换为相同帧尺寸 PNG；菜单预览提高栅格尺寸；背景压缩为 JPG；完整背景音乐转为 96 kbps MP3，未裁切；音效保留原 WAV。输出 `asset-manifest.json` 记录每项源文件与生成文件的 SHA-256，并附 Phosphor 图标许可证。

构建使用项目自定的保守 **4 MiB 总包预算**，超出即失败；这不是对平台所有包型限制的声明。当前完整包约 3.28 MiB，无远程素材或服务端依赖。

## 真机验收

在工具的自定义编译条件设置启动参数 `acceptance=1&seed=wechat-baseline-a`，编译后用工具的“预览”在微信真机打开。需要有该 AppID 的开发/体验权限。编译参数随预览条件传入，不使用浏览器 URL。普通游玩可省略参数。

按以下顺序验收并记录设备、系统、微信版本、基础库和结果：

1. 两主题与两皮肤交叉选择；检查浅/深色菜单、地图、动画、侧卡和实体视图，切换外观时对局继续。
2. 固定与浮动摇杆分别同时移动和放弹；右手松开后左手继续移动；拖出、取消、系统手势后没有粘住的输入。检查安全区、胶囊和四项边距。
3. 完成胜/负/超时结算；重试保持初始化，新开一局换种子，返回菜单再开始。连续重开检查音效无叠加或残留。
4. 按住控件切后台、锁屏或触发音频中断；返回保持暂停，手动继续无误放弹、位移或时间追赶。检查音乐首次播放、独立静音、恢复、跨局单实例和完整循环听感。
5. 修改边距、模式、音量、粒子和明暗，退出小游戏再进入，检查保存；恢复操作默认值不修改其他设置。
6. 正式 17×15、1对3、默认粒子96，持续前台游玩至少60秒；保留首局及后续局性能。若切后台或提前死亡，另开一局取得足时片段，不把零碎时段相加。

验收模式在暂停/结算面板提供“复制验收报告”（常规横屏高度）。复制 JSON 后粘贴保存为文件交回核对；报告不自动上传，最多保留最近12局。报告含实际初始化、设备、设置、帧时/逻辑耗时、补步与丢弃时间、音频实例及错误；人工项目须另附结果。只读诊断入口为 `GameGlobal.fakebombit.read()`，不提供改写对局的方法。

当前自动化与实际开发者工具证据见 [#17 移植验证](validation/issue-17-wechat-port.md)。桌面工具与模拟 wx 宿主测试不能代替上述真机验收。
