# #20 背景音乐与独立音量

2026-10-26，用户明确要求用提供的 `fbi_bgm.mp3` 作背景音乐，并在设置中分别调节背景音乐和炸弹等音效。实现提交 `0591ea0`；该新增请求替代此前视觉提案阶段“不新增音乐”的范围限定。

## 实现

- 原样复制到 `public/audio/fbi-bgm.mp3`，源文件保留。大小4,315,140字节，源文件/项目副本/生产构建副本SHA-256一致：`354669688dbb09aecef03671f567faf1ce656fd4ccc4713b9e6c899d3df92e3b`。浏览器解码时长200.388秒。
- `BackgroundMusic`在应用生命周期持有一个流式HTML audio，开启loop、metadata预加载。第一次用户指针或键盘操作后播放；菜单、准备、对局与结果共用位置，重试/新开/返回不新建播放器或跳到开头。
- 局内暂停与设置暂停音乐，关闭设置保持暂停，手动继续从原位置播放。菜单设置可以边播放边调整；后台入口立即暂停，恢复仍遵守既有手动继续规则。销毁时移除监听器、释放音频；播放Promise失败被捕获，不阻止玩法或排队补播音效。
- 音量分类包含“背景音乐”“音效”两个独立0–100%滑块。音乐默认35%，音效沿用45%；0仅静音对应声道。旧 `fakebombit-feedback-v1.volume`继续表示音效，新 `musicVolume`缺失时补默认值；粒子、操作和明暗偏好保留，操作重置不动音量。
- 音效仍使用既有Phaser按事件播放/清理机制，未改玩法模块、随机源、事件cursor或AI预算。音乐开销计入表现阶段，原Phaser声音实例计数继续只描述音效声音。
