# #10 安全地图生成与种子重试

2026-10-15 用户确认障碍概率 45%、最多随机尝试 12 次，再验证基础布局；逃生校验最多 6000 状态、向前规划最多 6 秒，均可配置。审查基准 `1b5a90c`。测试继续通过对局创建、推进、读取的公开接口，逃生证明对照真实步进。

用户要求地图尺寸参考 Bomb It 原版。依据 [Bomb It (2006) 原版截图](https://www.mobygames.com/game/175807/bomb-it/screenshots/browser/1075005/)及其[图像](https://cdn.mobygames.com/screenshots/15713421-bomb-it-browser-an-extra-bomb.png)逐格观察，内部约 15×13 格，本项目包含固定边框后默认采用 **17×15 格**。这是画面估算的参考尺寸，并非原作者公布的数值规格。截图参考保存在忽略产物 `.scratch/issue-10-bomb-it-original-reference.png`。

## 公平性与边界

- 四角出生，固定墙与障碍分别沿水平、垂直轴对称；每个出生点至少两个可起步方向、五个连通空格。
- 出生点曼哈顿距离不超过四格内，至少一个可破坏障碍，四个出生点的数量相同。
- 移除所有可破坏障碍后，四个出生点连通；初始无炸弹、火焰或道具。
- 对每个出生点，以当前规则、初始能力在脚下放一颗炸弹，复用实际放弹构造、中心线移动和危险预测，确认一条能等待全部火焰结束的安全路线。此检查针对各出生点各自的初始放弹，不承诺多人同时放弹后的联合安全，也不禁止玩家随后选择自困。
- 尺寸可配置为 7–25 的奇数格；概率为 0–1，随机尝试次数可为零，搜索状态数与规划秒数必须为正。基础布局保留对称资源障碍，同样通过全部检查；失败抛出 `MapGenerationError`，提供有限尝试记录及原因，不静默接受未确认路线。

生成使用独立的 `map-generation` 种子流，与放弹仲裁、掉落和拾取随机流分离。初始化记录保存解析后的生成配置、每次尝试及失败原因、最终来源和各出生点指标/逃生证明。重放重新生成并核对地图与记录；记录被改动时拒绝。实现标识为 match `generated-map-v1`、map `semantic-map-v1`、generator `symmetric-map-v1`、AI `escape-ai-v1`；旧版初始化记录明确拒绝。

## 浏览器行为

默认页面生成地图，`?seed=...` 可重现初始地图，完整种子保存在地址栏与画布可访问标签中。右侧显示种子、格数和新开一局按钮；R / 重试建立新对局、输入、事件消费上下文，使用原初始化记录；N / 新开一局选择不同种子并清空原上下文。浏览器生成新种子使用宿主加密随机源，该依赖留在浏览器组合根中。创建失败显示恢复入口，停止玩法输入。

地图按预留区域等比例缩放，触屏摇杆和放弹按钮保持原尺寸。`?arena=training` 保留原固定训练地图；道具与逃生练习入口继续保留。

## 验证

针对性测试已覆盖 12 个种子的对称、资源和清障连通，真实炸弹步进验证各出生点逃生证明，零次/耗尽重试的基础布局，无法逃生与预算不足的有限失败，非法配置，以及生成记录、逐步世界状态和事件复现。

Codex 内置浏览器的 1280×720 默认视口、844×390 横屏模拟视口均检查了完整棋盘、标签、种子与操作区，未见遮挡或溢出。实际键盘操作完成移动、放弹、暂停；画布重试后同一种子/障碍布局、玩家回到 `(1.5, 1.5)`、炸弹和已消费事件数归零；画布新开后种子与地图均变化，起始上下文归零。横屏新开按钮及键盘 R 重试同样通过。

非法空白种子显示明确失败页面，N 恢复生成新局；核心另行验证 `generation-failed` 的有界诊断，没有把非法种子的浏览器用例视作生成失败覆盖。既有道具/逃生固定练习场继续正常初始化。浏览器控制台无错误，临时视口已恢复、临时标签已关闭。本次未新增真机触屏或手机性能覆盖。
