# 独立对局模块掌握规则与固定步进

本项目需要让同一套规则支持触屏、键盘、AI、实体视图与不同主题，并能在没有图形环境时验证完整对局。采用不依赖 Phaser、浏览器或视觉资源的纯 TypeScript 对局模块，集中掌握地图生成、移动、碰撞、炸弹、道具、AI 和胜负；对外只提供创建对局、推进一步、读取只读世界状态三类操作。

规则按固定时间步推进，表现按实际渲染频率插值；初始考虑每秒 60 步，具体频率经性能验证后确定并按局冻结。游戏流程模块驱动步进，对局通过有序事件与只读状态交付结果，表现不得反向决定伤害、计时或能力。主要测试经对局模块的公开接口验证外部行为。

相较于在 Phaser 场景和回调中分散规则，这一选择增加了明确表达世界状态、时间和表现同步的工作，但能够保持规则独立、让输入与渲染频率不改变对局行为，并为种子复现和后续平台适配保留稳定接口。首版使用显式世界数据，不引入完整 ECS 或全局事件总线。

完整接口、配置与测试约定见 [架构规格 Issue #2](https://github.com/tee229/fakebombit/issues/2)。
