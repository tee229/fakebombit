# Gameplay Logic ≠ Visual Style

本项目需要支持不同主题包、角色皮肤和实体视图，同时保持一致的移动、炸弹、道具及胜负规则。采用语义化世界定义，由玩法逻辑掌握状态、规则与游戏时间，再由表现映射和 Theme / Skin / Asset Resolver 选择图片、动画、粒子与声音。

玩法逻辑不引用 PNG、spritesheet、动画帧或具体皮肤；地图的玩法层与视觉层独立，视觉层通过视觉槽位描述装饰布局。贴图尺寸、动画时长、附件和特效不得改变碰撞、伤害或能力，AI 与实体视图直接依据真实世界状态。碰撞与导航根据当前世界状态生成，避免分别保存冲突的玩法事实。

这一选择增加了资源约定与表现映射的设计成本，但能避免直接绑定贴图造成的地图、角色和规则耦合，并让换主题和调试视图共用同一套玩法逻辑。具体美术风格保持开放；首版支持内置资源包，外部导入和在线资源管理随后推进。

已确认的首版范围与验收条件见 [GitHub Issue #1](https://github.com/tee229/fakebombit/issues/1)。
