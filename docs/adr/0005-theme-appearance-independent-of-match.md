# 明暗外观联动界面与主题包，独立于对局

2026-10-20，用户确认需求变更：沿用一个明暗开关联动界面与当前主题包的明暗外观，覆盖地面、墙体、可破坏障碍、炸弹、道具和特效的可读性；角色皮肤仍独立选择。主题包提供明、暗两种外观，不需要差异的资源允许共用同一份。此为已确认的设计决定，2026-10-21已在 #19 接入。

明暗切换属于同一主题包的表现变化，保留当前对局进度，不重建对局初始化或改变玩法规则；这与既有每局固定主题包选择的约定相容。相比只调整界面配色，此选择需要明确主题外观变体与资源准备，但能避免界面和地图明暗割裂；共用资源允许保持原样的主题不必复制图片。

后续访谈确认在开局前准备好所选主题的两种外观，共用图片只加载一次；必要资源准备失败时提示重试。相比局内按需加载，这增加首次准备和资源占用，换取对局中直接切换、避免临时缺图或加载等待。明暗外观切换不重开对局。

完整确认规格、视觉样例顺序和验收条件见 [#19](https://github.com/tee229/fakebombit/issues/19)。本决策沿用 ADR 0001/0002 的玩法与表现所有权，不将外观选择写入玩法规则。2026-10-21 已实现同包双变体资源准备和局内外观解析，界面/主题共享开关；皮肤与世界保持独立，目标机复验仍待完成。
