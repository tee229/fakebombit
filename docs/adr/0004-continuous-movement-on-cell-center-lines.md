# 连续移动沿格子中心线，受阻时停在格子中心

早期原型允许角色走到碰撞体与墙接触的位置；默认碰撞半宽 0.3 格使停靠位置偏离格子中心 0.2 格，超过默认转弯容差 0.12 格，导致顶墙后无法横向转弯，并可能阻碍炸弹逃生。用户于 2026-10-14 确认采用中心线移动：保留连续四向行走与提前转弯，在墙、炸弹或地图边界前停在最后一个可通行格子的中心，使受阻位置可直接向开放方向转弯。

这一规则主动收紧了格子内的移动自由度，换取稳定的通道对齐与转向体验。松键停在两个中心之间后，垂直于原通路的新操作先按正常移动预算靠近可转向的最近中心；近中心的有限位置辅助仍由移动规则决定。表现插值沿实际水平、垂直转弯路径，而非跨角的对角线；碰撞体大小继续用于火焰伤害与炸弹离开权限，不由画面资源决定。

炸弹离开权限仍在完全分离时撤销；若撤销发生在两个中心之间，反向重新进入炸弹时停在当前位置，避免为了对齐而将角色推回另一中心。移动结果改变，因此对局实现标识更新为 `center-line-movement-v1`，拒绝旧移动规则的初始化记录；同版本的种子、初始化与操作仍可复现。相关实施任务为 [#3](https://github.com/tee229/fakebombit/issues/3) 与 [#6](https://github.com/tee229/fakebombit/issues/6)。
