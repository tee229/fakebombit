# 同一步连锁爆炸共用阶段开始时的阻挡状态

同一个逻辑步可能有多颗炸弹到期或发生连锁。如果每计算一颗炸弹就立即销毁障碍，后续爆炸可能穿过刚被销毁的障碍，结果会受遍历顺序影响。

同一步爆炸与连锁统一依据爆炸阶段开始时的阻挡状态计算，收集结果后再统一销毁障碍、结算淘汰等影响。被本步销毁的障碍仍阻挡本步所有爆炸，下一步使用更新后的世界状态；危险预测复用相同规则。

这种批量结算需要维护阶段状态和影响集合，但使结果不依赖炸弹遍历顺序，便于稳定复现与验证。不同逻辑步之间障碍状态仍正常更新，不把阶段状态扩展为整局固定地图。

完整逻辑步顺序与相关验证见 [架构规格 Issue #2](https://github.com/tee229/fakebombit/issues/2)。
